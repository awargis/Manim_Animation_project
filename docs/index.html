Make difficult ideas visible.

A starter project for cinematic, step-by-step educational animations using Manim Community Edition. Each episode begins with a question, builds a visual model, and gives learners a moment to predict what happens next.

Getting started

Your first render

01 · Set up

Install Python 3.11, FFmpeg, and the dependencies listed in requirements.txt.

02 · Customize

Edit the question heading and statement in main.py. Verify the physics and solution before publishing.

03 · Render

Run manim -pqh main.py IrodovQuestionDemo, or use the repository's GitHub Actions workflow to create an MP4 artifact.

Production note

Designed to grow

The included scene is an illustrative circular-motion visual—not a solution to a specific Irodov question. Replace the sample prompt with a question you have permission to reproduce, then check every equation, diagram, and conclusion for accuracy.
